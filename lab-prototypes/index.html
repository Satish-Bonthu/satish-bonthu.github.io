Room Resonance Lab

Problem
Room modes are difficult to picture from a list of frequencies.
Proposed solution
Make modal frequencies and pressure patterns explorable.
How it was approached
Built an interactive prototype linking room geometry to its modal patterns.
Level of difficulty
Intermediate · Spatial modes must remain interpretable as geometry changes.
Value and takeaway
Helps explain how room dimensions affect resonance.

Demonstration only · Unreviewed prototype. Use it for exploration. Constructive feedback is welcome.

Exciting a furnished room

Problem
Different sound sources can excite different modes in the same room.
Proposed solution
Compare the response to sources such as a clap, whistle, and balloon pop.
How it was approached
Planned study using a common source-strength convention to compare modal responses.
Level of difficulty
Advanced · Source normalization and modal excitation must be handled consistently.
Value and takeaway
Would illustrate the link between natural modes and forced response.

Planned demonstration · Unreviewed concept. Constructive feedback is welcome.
