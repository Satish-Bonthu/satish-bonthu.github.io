Room Resonance Lab

Explore how room geometry changes natural frequencies and the spatial shape of acoustic modes.

Request a guided demo

About this lab
Problem
Room modes are difficult to picture from frequencies alone.
Proposed solution
Make the pressure patterns and frequencies visible together.
How it works
Adjust the room and explore modal fields, phase animation, and receiver behavior.
Level of difficulty
Intermediate · Interpreting spatial modes and nodal patterns.
Value and takeaway
See how geometry and receiver placement affect the acoustic response.

Room Excitation Lab

Compare how different sound sources excite the same furnished room.

Request a guided demo

About this lab
Problem
Different excitations can produce different responses in the same room.
Proposed solution
Compare source signals and the room modes each excites.
How it works
Use a furnished-room demonstration to explore the link between excitation and response.
Level of difficulty
Advanced · Source normalization and modal coupling.
Value and takeaway
See why the sound you use to excite a room affects which modes are visible.

Didgeridoo Lab

Explore the link between instrument bore geometry and resonance.

Request a guided demo

About this lab
Problem
Bore geometry affects an instrument’s resonance frequencies.
Proposed solution
Make the geometry and resonance behavior explorable in a dashboard.
How it works
Use the interactive model to examine how bore parameters affect resonance.
Level of difficulty
Intermediate · Relating bore geometry to standing waves.
Value and takeaway
Build intuition about why changing an instrument’s dimensions changes its sound.
